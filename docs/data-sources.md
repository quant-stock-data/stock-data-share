# 数据源说明

[中文](./data-sources.md) | [English](./data-sources_en.md)

本项目采用多来源组合，而不是依赖单一网站。不同来源负责自己更擅长的数据类型。

## 数据源总览

| 来源 | 用途 | 接入方式 | 备注 |
|---|---|---|---|
| 腾讯财经 | 实时行情、日 K、分钟 K | HTTP | 作为行情主入口 |
| 新浪财经 | 财务三表 | HTTP | 沪深股票 |
| 巨潮资讯 | 上市公司公告 | HTTP | 沪深北公告 |
| 东方财富 | 公司资料、研报、两融、大宗、股东户数、分红、资金流 | HTTP | 统一限流 |
| baostock | 历史估值、上市基础信息 | Python client | 可选依赖，不覆盖北交所 |
| 国家统计局 | PMI | 官方网页 | 从最新发布页解析 |
| 上交所 | ETF PCF、监管事件 | 官方接口 / XML | 保留来源信息 |
| 港交所 | Stock Connect 资格清单 | 官方 CSV | 支持 eligible / sell-only |

## 设计原则

### 行情优先走腾讯

实时行情和 K 线属于高频常用能力，因此使用独立的腾讯 provider，避免把所有能力集中到单一来源。

### 公告优先走巨潮

上市公司公告通过巨潮查询，并返回公告详情页和附件地址。

### 东方财富承担专门的数据层

东方财富 provider 主要承载：

- 公司资料
- 个股 / 行业研报
- 融资融券
- 大宗交易
- 股东户数
- 分红
- 历史资金流

相关 HTTP 请求统一经过 `RateLimitedSession`，同一实例串行执行。

### 官方事件型数据优先保留证据字段

对交易所文件和名单，结果尽量保留：

- `source`
- `source_url`
- `fetched_at`
- `content_sha256`

这样更适合后续做历史归档和事件研究。

## 已知限制

- 公共网页和未承诺稳定性的接口可能随时调整。
- 不同网络环境对东方财富部分接口的可访问性可能不同。
- baostock 当前不支持北交所代码。
- 腾讯 K 线在当前实现中不把北交所作为可靠覆盖范围。
- 国家统计局 PMI 依赖最新发布页面的文本结构。

遇到上游结构变化时，项目倾向于显式报错，而不是返回一个看似正常的空结果。
