# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-30

### Added

- Unified `AShareData` facade.
- Tencent quote and daily/minute K-line providers.
- Sina financial-statement provider.
- CNINFO announcement provider.
- Eastmoney company profile, research, margin trading, block trade, shareholder count, dividend, and fund-flow endpoints.
- Optional baostock historical valuation provider.
- National Bureau of Statistics PMI provider.
- SSE ETF PCF and listed-company regulatory-event providers.
- HKEX Stock Connect eligibility-file provider.
- CLI commands for common queries.
- Chinese and English documentation.
- Unit tests, live smoke checks, and Ruff configuration.

### Notes

- Public data interfaces may change independently of this project.
- Source metadata is retained where practical to make results easier to verify.
